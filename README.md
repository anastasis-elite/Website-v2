# Anastasis Site Starter

A luxury black-and-copper Next.js starter homepage built for Vercel deployment.

## Quick start

```bash
npm install
npm run dev
```

## Work from an iPad

### Edit the project in Safari with GitHub Codespaces

1. Open the repository on GitHub in Safari.
2. Select **Code > Codespaces > Create codespace on main**.
3. Wait for setup to finish. Dependencies install automatically and the website
   preview opens on port 3000.
4. Edit and save files in the browser-based editor. Use the Source Control panel
   to commit and sync your changes back to GitHub.

The first Codespace takes a few minutes to build. Later sessions can resume the
same Codespace. Stop it from the Codespaces page when you are finished so it does
not consume usage time.

### Preview the Mac's local copy on an iPad

The Mac and iPad must be connected to the same Wi-Fi network.

1. On the Mac, run `npm install` once and then `npm run dev:ipad`.
2. Find the Mac's address under **System Settings > Wi-Fi > Details > IP Address**.
3. Open `http://MAC-IP-ADDRESS:3000` in iPad Safari.

If macOS asks whether to allow incoming connections for Node, choose **Allow**.
Stop the preview with **Control-C** when finished.

## Deploy to Vercel

1. Push this folder to a new GitHub repository.
2. In Vercel, click **Add New > Project**.
3. Import the GitHub repository.
4. Vercel should auto-detect Next.js.
5. Click **Deploy**.

## What to replace first

- Swap the `LOGO` placeholder in `app/page.tsx` for your actual mark or image.
- Update `hello@yourdomain.com` to your real application/contact email.
- Add your brand fonts once you choose the exact type pairing.
- Expand the homepage into sections like Programs, Method, Proof, FAQ, and Apply.
